# Changelog

## - [5.0.3] 2026-08-24

### Added
- **Инлайн Web Worker для виджетов:** Внедрен механизм асинхронной неблокирующей подгрузки JS-скриптов enterprise-виджетов через динамически генерируемый `Blob URL` Web Worker прямо внутри `ReactiveScriptEngine`.
- **Двусторонняя реактивная синхронизация:** Добавлен контракт обмена данными (`window.ThreadsWidget.onStateChange`) между сторонним JS-скриптом виджета и `ReactiveEngine` для сквозного прокидывания стейта (счетчик, тема) в React без ререндеров страницы.
- **Пульт управления API виджета:** Реализован интерактивный UI-блок контроля на стенде, позволяющий триггерить нативные методы глобального объекта `window` (инкремент уведомлений, переключение темы) напрямую из React через прокси-методы сервиса.
- **Эффект Glassmorphism:** В стили плавающего виджета добавлен современный эффект матового стекла с аппаратным размытием заднего плана через `backdrop-filter: blur(12px)`. Фоновые градиенты переведены на полупрозрачный формат `rgba`.
- **Защитный таймаут поллинга:** Внедрен предохранитель, автоматически прерывающий интервальный пинг глобального объекта `window.ThreadsWidget` через 30 секунд в случае скрытого сбоя или падения серверов вендора.
- **Инфраструктура Webpack Bundle Analyzer:** В `next.config.js` интегрирован плагин `webpack-bundle-analyzer` для глубокого аудита веса клиентских и серверных чанков без автоматического прерывания работы терминала (`openAnalyzer: false`).

### Changed
- **Оптимизация бандла рендереров (Code Splitting):** Главный монолит кастомных Markdown-компонентов (`./src/react-markdown-renderers`) успешно разделен на изолированные ленивые чанки с помощью `next/dynamic`.
- **Изоляция тяжелых компонентов:** Код компонента `Alert` вынесен в асинхронный чанк `7902`, а интерактивный стенд `EdnaExp` вместе со строкой кода воркера и реактивным сервисом изолирован в чанк `7018`. Общий вес монолита рендереров на клиенте снизился с **63.35 KB** до **44.86 KB** (экономия ~30%).
- **Выпрямление путей Webpack Analyzer:** Логика сохранения отчетов анализатора переписана с относительных путей на жесткие абсолютные через `path.resolve(process.cwd(), '.next/static/analyze')`, что решило проблему «разлетания» клиентского и серверного HTML-файлов по разным скрытым системным папкам Next.js.

### Fixed
- **Race Condition при старте виджета:** Решена проблема рассинхронизации таймингов, из-за которой начальный стейт виджета не затягивался в сигналы `ReactiveEngine` до первого клика. Теперь первичные данные подсасываются мгновенно в момент обнаружения объекта в фазе поллинга.
- **Утечка тегов при сбросе (Idempotency):** Переписан метод `reset()` в `EdnaScriptService`. Теперь при очистке стенда из заголовка `<head>` бесследно удаляется сам созданный тег `<script id="edna-experimental-script">`, предотвращая дублирование кода при повторной инициализации.
- **Конфликт PWA Scope и Blob Workers:** Добавлено жесткое правило-исключение `NetworkOnly` для внешнего домена скрипта в массив `customRuntimeCaching` внутри `next.config.js`, что предотвратило перехват fetch-запросов воркера сервис-воркером установленного приложения внутри `scope: '/blog/'`.
- **Ошибка компиляции Webpack Context:** Исправлена критическая ошибка `ReferenceError: isServer is not defined` в конфигурации сборщика путем корректной деструктуризации объекта контекста Next.js во втором аргументе метода `webpack(config, { isServer })`.
