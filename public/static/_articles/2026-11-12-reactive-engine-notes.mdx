2. Прогоняем локальные тесты (при возниновении сюрпризов дописываем тесты и фиксим их через TDD):
```bash
yarn test
```
3. Прогоняем тесты на производительность (если в их проблема - разбираемся в причине):
```bash
yarn test:dynamic
```
4. Проверяем работоспособность существующих примеров в UI чтобы убедиться, что мы ничего не пропустили (примеры, вроде, исчерпывающие, но если что-то из них не работает - нужно разобраться, дописать тесты и поправить их через TDD):
```bash
yarn start
```
5. Релизим альфу
6. Прогоняем альфу на семантику графа 👉 [/johnsoncodehkreactive-framework-test-suite](https://github.com/johnsoncodehk/reactive-framework-test-suite)
7. Если все устраивает, прогоняем альфу на производительность 👉 [github.com/transitive-bullshit/js-reactivity-benchmark](https://github.com/transitive-bullshit/js-reactivity-benchmark)
8. Релизим минор/мажор
