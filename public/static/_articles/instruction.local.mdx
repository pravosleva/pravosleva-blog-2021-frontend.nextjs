# Instruction
## Q
Как быть, когда однажды code-samples.space станет недоступен?

## A
1. Используйте директорию `/public/static/_articles/*` для хранения статей.
2. Slug статьи - это имя файла (без расширения)
3. На переходный период можно создавать клоны статей с добавлением в имени `.local` (потом избавиться - ссылки будут актуальны)
4. Ликвидировать обращение к удаленному ресурсу в файлах:
   * `srv.express-next-api/router/code-samples-proxy/api/notes/[id].ts`
   * `srv.express-next-api/router/code-samples-proxy/api/notes/index.ts`

### Алгоритм пока следующий:
- Поиск локального файла 👉 Поиск в сети 👉 UI Error
- Путь к целевой странице (когда удаленная база будет недоступна) + переходный период 👉 `/p/[slug]`
