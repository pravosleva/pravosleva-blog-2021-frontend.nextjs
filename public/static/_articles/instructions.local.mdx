## Q
Как быть, когда однажды code-samples.space станет недоступен?

## A
1. Используйте директорию `/public/static/_articles/[slug].mdx` для хранения статей.
2. `slug` статьи - это имя файла (без расширения)
3. На переходный период можно создавать клоны статей с добавлением постфикса `.local` в имени (потом от него избавиться - ссылки будут актуальны)
4. Ликвидировать обращение к удаленному ресурсу

### Алгоритм пока следующий:
- Поиск локального файла 👉 Поиск в сети 👉 UI Error
- Путь к целевой странице в любом случае `/p/[slug]`
